# State git practice (sandbox)

> **⚠️ This repository is PUBLIC.** Anyone on the internet can read everything here, including issues, pull requests, comments, branch names and commit messages (and they stay in the history even if deleted later). **Do not put real or sensitive information anywhere in this repo.** That means no real Index data, unpublished findings or rankings, internal Tax Foundation discussion, links to private repos or documents, or personal details. Use the fake data provided and invent your own for practice.

Practice repo for the state team before the Index update. **All data here is fake.** It copies the shape of the real
repo (`input/<year>/<subindex>/topic.csv` plus `dictionary.csv`, the BOM and dictionary pre-commit hook, the
dictionary check on pull requests, and the same "Protect Main" rules) so habits carry over.

- First-time setup: `git config core.hooksPath .githooks`
- How we work: [CONTRIBUTING.md](CONTRIBUTING.md)
- Exercises: [exercises/](exercises/), do them in order
